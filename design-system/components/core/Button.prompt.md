Stratum's primary interactive control. Use for all user actions.

```jsx
<Button variant="primary" icon="plus">Zeit erfassen</Button>
<Button variant="secondary" icon="download">Export</Button>
<Button variant="ghost">Abbrechen</Button>
<Button variant="danger" size="sm">Löschen</Button>
```

Variants: primary (sage accent), secondary (surface + border), ghost (transparent), danger (red-tinted).
Sizes: sm (11px), md (12px, default), lg (13px).
Icons: pass an Icon `name` string to `icon` (left) or `iconRight` (right).
